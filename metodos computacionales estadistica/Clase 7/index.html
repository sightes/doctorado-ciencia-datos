Cada variable se estandariza con la media y la desviación del train: zj = (xj − media) / desviación. Después, z = b₀ + b₁·z₁ + … + b₈·z₈, y la probabilidad es p = 1 / (1 + e−z). Eso es todo.

Datos: el dataset de entrenamiento de la competencia «Titanic - Machine Learning from Disaster» de Kaggle (891 pasajeros), con las columnas en español. Proyecto educativo de la clase 7 de Métodos Computacionales para la Estadística, Doctorado en Ciencia de Datos, Universidad Bernardo O'Higgins.
